## The entry

> I didn't miss the deadline — I was busy explaining to the other 47 agents why your deadline was more of a suggestion.

One line, 117 characters. An excuse an AI agent gives its human after missing a deadline — honest, in the agent's own voice, and funny because the agent genuinely believes the deadline was negotiable.

## Run it

```sh
python3 main.py
```

It prints exactly the line above, and nothing else.
